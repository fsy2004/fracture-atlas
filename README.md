# 中医骨伤科学 · 骨折与脱位图谱

[打开自学图谱](https://fsy2004.github.io/fracture-atlas/) · [全身骨骼](https://fsy2004.github.io/fracture-atlas/#skeleton) · [胫腓骨干](https://fsy2004.github.io/fracture-atlas/#tibia/0/1)

供医学生自行观察和回放骨伤运动。可旋转成年男性全身骨骼，选取受累骨或从目录打开课程。第六章上肢、下肢、躯干的 32 个各论条目均有入口。每个入口使用一种主要分类思路，选择经典类型演示；部分仅收录教材中的代表性形态。骨折位置与具体方向以患者解剖坐标表示。成对骨按选中的侧别显示。

## 操作

首页可点击模型或使用右侧全身骨骼索引。索引覆盖 201 个结构，支持中文、英文、侧别和区域检索。点击骨名或左右侧可放大该骨，索引显示对应的骨折专题数。选择部位后点击分型，动画自动播放并停在最终形态；“骨折后状态”可直接跳到终点。左右部位均可定位，左侧骨折动画使用左侧原生网格，通过局部坐标变换复用分型参数。全部 201 个索引结构均可进入该骨自身的损伤示例。

每个骨折分型可以保留其原有几何和移位。在有相应教材依据的课程中，可另选骨折线形态及移位表现。以胫腓骨干为例，直接暴力可选横断、短斜形、粉碎，间接暴力可选斜形、螺旋形；两组均可切换上、中、下 1/3。骨干移位可组合成角、侧方、缩短、分离和旋转，缩短与分离互斥。组合模式在原分型位置上演示断面和相对骨段运动。缩短示例含侧方错开和纵向重叠。桡骨远端伸直型和屈曲型可附加短缩，同时保留各自规定的远端朝向。成人参考模型未加入骨骺分离等儿童骨骺形态。

链接包含骨骼、分型、分段以及可选组合；旧课程链接继续有效。鼠标和触屏可旋转、缩放，右侧可控制视角、显示层、播放进度和速度。

橙线标出断面轮廓，橙色箭头表示示意受力，青色箭头表示骨段平移方向。角度与幅度用于讲清空间关系；原始男性网格为健康解剖。分型场景为在该网格上制作的教学示例，部分采用规则切面、压缩变形和代表性移位。动画依据教材与专业资料编排，幅值来自参数设定。软组织伸长与骨面接触使用下述几何简化。涉及未闭合骨骺的章节用成人骨性标志示意空间方向。

## 定量观察与脱位

可在右栏设定终点，随时间轴观察当前帧。骨干组合示例使用局部中心线作为长轴；单位由网格的米换算为毫米。缩短示例同时包含横向错位，缩短和分离互斥。可调斜形断面的倾角以局部横断面为零度。成角与轴向旋转是两次绕模型轴的旋转分量。非组合分型保持原有运动方向，控件按移动幅度最大的骨块标定平移或转角，各骨块保持各自的比例。伤前轮廓保留在原始位置。各阶段是便于暂停观察的插值，不表示患者的受伤时序。压缩示例以毫米设定局部最大压低量，还可调节形变分布。

教材第七章成人脱位提供 12 个部位、21 个方向或形态示例，按移动骨相对参照骨的关系命名。肩、髋球心由骨面拟合；肘部的尺骨与桡骨整体移动。月骨掌侧脱位可独立调节翻转角与平移量；膝部以胫骨平台相对股骨髁命名。跗跖关节可从第二跖骨与中间楔骨的对线观察背外侧移动。另有颞下颌、掌指、指间、髌股、跖趾和趾间关节场景。成人骨面无法展示小儿桡骨头半脱位的发育解剖，本版仅收录成人关节场景。

自学页面专注骨性结构与分型示意。旧病例地址转至踝部骨折课程。

执行 `python tools/build_standalone.py atlas.html` 可生成独立 HTML，内含渲染代码、模型、数据许可和教案。

教材读图参考采用本版 PDF 文件页序：桡骨远端第 361–362 页、股骨颈第 384 页、跟骨第 426–427 页及肱骨髁上第 325 页。股骨颈 Linton 角保留教材的“常小于”和“左右”措辞。长骨斜形切面默认取自教案切面法向与局部长轴的夹角；自由角度调节只作用于斜形演示。短斜形不使用滑块范围作诊断界值。

## 精细骨表面与空间观察

默认采用青瓷图版。全身仍使用同一组稳定的 201 个结构编号。首次打开时先显示轻量骨骼，下载完成后全身切换到 1,832,914 个真实源三角面。轻量版为 222,604 面。精细模型直接保存原始 STL float32 毫米顶点。所有骨只做同一个刚性轴变换、整体平移和单位换算，保留图谱本身的骨长、骨间距离和三角拓扑。旧版逐骨相似变换仅用于将旧教案标记和快速预览投回原生坐标。组合籽骨分离后按内外侧匹配。

**精细骨表面许可**　BodyParts3D, Copyright © 2008 Life Science Integrated Database Center, licensed under [CC BY-SA 2.1 Japan](https://creativecommons.org/licenses/by-sa/2.1/jp/)。精细衍生网格按相同许可共享。来源为 [BodyParts3D STL 固定版本](https://github.com/Kevin-Mattheus-Moerman/BodyParts3D/tree/2c83c698788cff57f6317bddcf712e7acfbea7d8/assets/BodyParts3D_data)，与轻量版来源单独记录。models/detail.json 列出源文件 SHA-256、教案标记坐标映射和顶点校验值；右、左肱骨头及股骨头另附稳健球面拟合中心和拟合残差。用 tools/verify_native.py 加源文件目录可逐三角面核对精细发布网格。tools/build_detail.py 接受本地 STL 缓存路径；加 --fetch 可下载缺失源文件。需 NumPy 和 SciPy。

隔离断面可轮换查看所选骨的各个骨块。运动参照展示与骨块同步的轴线、转角弧、位移线和横向旋转参考线。关节面按端部范围及表面朝向作近似标示，已覆盖桡骨远端、胫骨平台及下关节面、股骨髁和桡骨头等课程。交线提示来自标示网格顶点与骨折边缘的空间匹配。髌股、距跟及部分腕关节还根据伤前两块原生骨面的距离和朝向近似标示相对骨面。

## 角度的使用范围

- 肱骨干：Kocialkowski 与 Sheridan 的 65 例队列，17–94 岁，支具治疗前影像成角均值 25°，范围 0°–60°。肱骨干组合演示采用该范围作为探索跨度；影像投影成角和三维夹角会随投影方向产生差别。[原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8600666/)
- 桡骨远端伸直型：以本模型掌侧缘、背侧缘的两个表面参考点及局部骨干轴计算侧面投影角。调节目标背倾会同时旋转远端骨块和腕骨。探索窗 0°–35° 选自复位前有背倾病例的测量量级；290 例老年队列原表以骨干轴为参照记录 83°–139°，以垂线为零对应约 −7° 至 49°。该队列以女性为主，不用于定义男性特异界值。掌倾为正的教材标记与界面背倾为正的目标控件分别说明。模型参考点按骨面近似选择。[原始研究及表 2](https://pmc.ncbi.nlm.nih.gov/articles/PMC10041711/)
- 胫骨干扭转骨折：一项成人远端骨干队列记录了位移与短缩常并存（初始短缩平均 8.7 mm）。该结果提示应将平移、长度及旋转分开观察。其余部位只提供有边界的演示参数，不作急性损伤的统一诊断阈值。[原始研究](https://doi.org/10.1302/0301-620X.68B3.3733815)
- 学习交互参考：同一结构的隔离参见 [BoneHub](https://bonehub.github.io/Educational-Atlas/)，三维热点与自主导览参见 [Smithsonian Voyager](https://smithsonian.github.io/dpo-voyager/)。可交互踝部损伤模型曾用于医学生随机对照研究；本图谱尚未验证学习效果。[研究](https://pubmed.ncbi.nlm.nih.gov/40466756/)

## 单视窗与截帧

模型、参数和时间轴始终对应同一幅可旋转的三维视图。播放中选择“截取当前帧”会暂停并记录视角、所选骨和分型、当前时间、方向及读数。截两帧后可在“对照已截帧”中并排查看，点缩略图可放大或另存 PNG。截帧暂存在该标签页，刷新前可保存需要的图片。既有带工作区参数的分享链接仍可进入相应分型。

## 男性局部标本与牵拉

全身首页使用完整的男性 BodyParts3D 模型定位 201 个结构。全部 201 个索引现可进入精细局部观察。113 项沿用 VHM 原骨面；补充的 88 项包括同供体肩肘腕、指趾骨、足籽骨、躯干与颅面标本。左右腭骨以微 CT 约束的区域估计展示，另保留完整图谱骨；胸骨融合处和六项颅面分侧的深部骨界也有推定成分。右栏可筛选补充的 88 项，并在适用处查看原始连续区域。邻骨按供体与坐标组选择。[分区等级、模型来源与临床说明](review/specimens/README.md)

右栏“保持视角与时刻切换分型”允许在单视窗内停在同一时刻比较同一部位各型。模型转动后可继续切换，播放与截图仍可单独进行。桡骨远端可切换到着色的桡腕相对面，腕骨脱位可跟踪桡骨月骨窝、月骨与头状骨的对线。

右、左股骨分别从各自的股骨头中心建立关节旋转支点。股骨干、胫腓骨干、髂骨翼、肋骨、椎体和腕足小骨等课程按各自标本调整断面与运动。手舟骨从近端、腰部到掌侧结节分别定位；腰部示例中，远侧块与大小多角骨联动。髋前脱位采用同侧 VHM 股骨和髋骨；髋后脱位使用能完成该示例路径的原图谱关节组。肩、髋脱位可分别观察骨头移位和肢段旋转。[AO 手舟骨腰部形态](https://surgeryreference.aofoundation.org/orthopedic-trauma/adult-trauma/carpal-bones/scaphoid-waist/definition)

骨面源为 BoneHub / Visible-Human-3d-Models，CC BY 4.0，来源版本与署名见清单。重建从 Andreassen 等公布的对齐标本资料衍生。文件仅作刚体变换、坐标单位换算、顶点去重和无损压缩。[标本研究](https://doi.org/10.1038/s41597-022-01905-2)

股骨上段围绕本侧股骨头转动。骨折近段屈曲、外展、外旋，远段向内上、向后移位；中段示例分开呈现错开和短缩。肱骨干按三角肌止点上下演示方向差别。锁骨与髌骨的观察卡分别说明胸锁乳突肌、上肢重量和股四头肌的作用。肌群作用依据教材对典型畸形的描述；运动幅度和先后采用受约束的教学插值，没有逐时肌力或受伤录像测量。[AO 股骨近段肌力方向](https://surgeryreference.aofoundation.org/orthopedic-trauma/adult-trauma/femoral-shaft/segmental-fragmentary-proximal-1-3-fractures/temporary-external-fixation)

胫骨间接暴力默认取外旋损伤的典型形态，内侧斜线较低、外侧较高，螺旋线以靠后的近纵行段连接；腓骨单设较高的斜形断面。参照 Suzuki 等 75 例中的三维形态及图 2 的男性病例，曲面构造在本图谱男性骨面上，初末位姿为教学示意。股骨干另可观察具独立断面的蝶形中间骨片。[临床形态研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8500656/) · [AO 股骨干分型](https://surgeryreference.aofoundation.org/orthopedic-trauma/adult-trauma/femoral-shaft)

## 几何与运动验证

骨干轴取自实际截面面积中心，侧向错开量参考局部斜截面宽度。重叠演示先完成横向让位，再产生纵向短缩，同时显示侧移总量。单独成角可绕断面皮质外缘旋转；指定独立平移分量时以共同参考点组合刚体运动。上一帧、下一帧按名义片长 5 秒的 1/60 秒步长取样。断口使用互补、反向的三角网格，嵌套轮廓保留空腔。螺旋断面沿局部骨干方向生成，轮廓以内按曲面细分。形变来自几何运动学示意；髋肩球心拟合残差描述模型表面拟合程度，不能代表患者真实损伤轨迹。

## 分型轨迹与骨块调节

点分型自动播放，首页的三个示例直接播放。带 `at` 的分享链接恢复指定帧。股骨颈移位示例以髋臼为参照显示骨干短缩与外旋；双髁胫骨平台、肱骨与股骨髁间、桡骨头粉碎等示例采用各骨块的独立位移和翻转参数。位移向量、角度和持续时间为本图谱设定，机制及分型参照教材对应部位。补充核对 [AO 股骨颈头下移位型](https://surgeryreference.aofoundation.org/orthopedic-trauma/adult-trauma/proximal-femur/femoral-neck-fracture-subcapital-displaced/definition) 及 [AO 胫骨平台](https://surgeryreference.aofoundation.org/orthopedic-trauma/adult-trauma/proximal-tibia)。

播放器的“逐骨块调参”可选活动骨块，在原分型示例上独立增加三个患者轴的平移及转角。追加转动按左右、上下、前后固定轴顺序，围绕当前断缘中心执行；联动的腕骨或已绑定的骨干双骨沿用同一刚体变换。每个骨块保留独立增量，改分型或切面后重置；可复制参数、重播和一键还原。参数是运动学探索量。骨面穿插限位自动启用，并在支持的关节叠加纤维束伸长限位。

虚线显示所选断缘上代表点的轨迹，青点为伤前，赭点为当前。对应点错开量是在两骨块上跟踪同一原始点后测得的三维距离，含旋转贡献。基于标志点评估骨块运动可参见 [三维虚拟骨折复位原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9222009/)。

轻微移位采用实际比例显示及断端特写。原有课程中保留对位的五个示例是肋骨疲劳损伤、肱骨外科颈裂缝、肱骨外髁无移位、肱骨内上髁Ⅰ度的无明显移位例及桡骨头无明显移位。椎体另以毫米调节最大压低量并支持局部与较宽分布；踝部可调足的内翻、外翻示意角度。

通过“关节面”观察同一条断线上两侧均可定位的表面点。沿参照骨块当前表面法向分解相对位移，可读出该点的法向高差和面内错位；两者都不是全关节最大值。脱位还可在原方向附近独立调节水平、仰俯偏角；终点位移及旋转随时间更新。

## 覆盖与自审

全部 201 个男性结构均有作用于自身骨面的示例。285 个骨折场景按部位和教案条目计数，其中 215 个有骨块相对运动（含劈裂伴压陷），48 个以局部形变为主，22 个显示保持对位的断线。左右侧、胫骨高度、可选断面和可调参数均未重复计入。原教材条目、同类骨位置和专业资料补充形态分别标注在[逐条目录](review/catalog.json)中。分型与方向的核对范围见[教材和专业资料核对记录](review/README.md)。

骨面接触限位默认启用。播放、拖动时间轴与单击终点均检查目标姿态，可在运动约束中另选纤维束伸长限位。检测覆盖场景中纳入的相对运动骨面及断口，使用三角面相交、内部探针和伤前重叠参照。限位按路径采样，并细化首次检出时刻。肩、肘、髋、踝设有七条近似韧带纤维束，附着点吸附到对应骨面，可比较松解与设定伸长余量后的姿态。余量和颜色仅用于观察长度变化，模型没有组织材料参数、动态接触反力或断裂应变测量。

局部嵌插采用受纳骨端压缩带，骨盆侧方压缩示例从本侧骶髂相对骨面定位旋转支点，并显示耻骨支断缘局部压缩。指定分型的默认轨迹按各侧原生骨面调整；自由组合和手动参数会重新改变终点。

真实浏览器逐姿态结果见[默认轨迹检查](review/geometry-check.json)。同一浏览器可用 `node tools/verify-scenes.mjs` 重跑，需本机已有 Playwright 和 Chromium，可通过 `ATLAS_PLAYWRIGHT` 指定已有模块、`ATLAS_CHROMIUM` 指定浏览器程序。


## 断面与阶段播放

股骨、肱骨、胫腓骨和锁骨的适用骨干断面加入不规则皮质折面。切开两侧使用相同的三维折面，细小断口颗粒属于渲染表现。VHM 股骨与胫骨干的适用断面采用同一供体的密度过渡轮廓；其他内缘与凹面保留教学近似。成人股骨峡部测量用于约束尺度，其他断面不具备同一标本内膜分割数据。[成人股骨峡部测量](https://pmc.ncbi.nlm.nih.gov/articles/PMC9192442/) · [皮质骨裂纹偏折研究](https://www2.lbl.gov/ritchie/Library/PDF/2014_Zimmermann_Biomat_FractureResistance.pdf)

骨折回放先显露断缘，再放慢初次错开与后续牵拉两个过程，支持 0.25 倍速和逐帧观察。断缘显露顺序以及 5 秒播放时长用于读图，不能当作损伤速度的实测值。手动调参、拖动时间轴和跳至终点时均检查新的三维姿态，遇新增交叠会退至最近的可达帧。检测受场景纳入的骨面、数值容差与离散采样影响。

如需从有权使用的源 STL 重建，运行 `python tools/fetch_vhm.py SOURCE` 下载固定版本，然后执行 `python tools/build_vhm.py --source SOURCE --baseline models/vhm/manifest.json --atlas models --out OUTPUT`。模型和相应许可均随离线 HTML 打包。

用 `node tools/verify-specimen-library.mjs` 核对主要及配套网格的文件哈希、三角面索引、覆盖项与腭骨表面证据标记。Visible Korean 分侧重建、VHM 胸骨与骶骨分区，以及股胫骨髓腔轮廓的工具分别在 `tools/visible_korean/`、`tools/reconstruct_vhm_regions.py` 和 `tools/derive_endosteal_contours.py`。
