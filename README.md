# 中医骨伤科学 · 骨折与脱位图谱

[打开自学图谱](https://fsy2004.github.io/fracture-atlas/) · [全身骨骼](https://fsy2004.github.io/fracture-atlas/#skeleton) · [胫腓骨干](https://fsy2004.github.io/fracture-atlas/#tibia/0/1)

供医学生自行观察、回放和回忆骨伤运动。可旋转成年男性全身骨骼，选取受累骨或从目录打开课程。第六章上肢、下肢、躯干的 32 个各论条目均有入口。每个入口使用一种主要分类思路，选择经典类型演示；部分仅收录教材中的代表性形态。骨折位置与具体方向以患者解剖坐标表示。右侧肢体为演示侧。

## 操作

首页可点击模型或使用右侧全身骨骼索引。索引覆盖 201 个结构，支持中文、英文、侧别和区域检索。点击骨名或左右侧可放大该骨，索引显示对应的骨折专题数。选择部位后点击分型，动画自动播放并停在最终形态；“骨折后状态”可直接跳到终点。左右部位均可定位，左侧骨折动画采用右侧教案的镜像。未编制分型的骨骼提供解剖观察。

每个骨折分型可以保留其原有几何和移位。在有相应教材依据的课程中，可另选骨折线形态及移位表现。以胫腓骨干为例，直接暴力可选横断、短斜形、粉碎，间接暴力可选斜形、螺旋形；两组均可切换上、中、下 1/3。骨干移位可组合成角、侧方、缩短、分离和旋转，缩短与分离互斥。组合模式在原分型位置上演示断面和相对骨段运动。缩短示例含侧方错开和纵向重叠。桡骨远端伸直型和屈曲型可附加短缩，同时保留各自规定的远端朝向。成人参考模型未加入骨骺分离等儿童骨骺形态。

链接包含骨骼、分型、分段以及可选组合；旧课程链接继续有效。鼠标和触屏可旋转、缩放，右侧可控制视角、显示层、播放进度和速度。

橙线标出断面轮廓，橙色箭头表示示意受力，青色箭头表示骨段平移方向。角度与幅度用于讲清空间关系；原始男性网格为健康解剖。分型场景为在该网格上制作的教学示例，部分采用规则切面、压缩变形和代表性移位。没有进行患者运动反演、力学计算或骨科教师逐型审校。涉及未闭合骨骺的章节用成人骨性标志示意空间方向。

## 教材与模型

- 教材依据为黄桂成、王拥军主编的《中医骨伤科学》，全国中医药行业高等教育“十四五”规划教材，第六章。每课列出章节、图号或 PDF 页序。仓库只含自行编写的简短讲解及动画参数。
- **BodyParts3D, © The Database Center for Life Science licensed under CC Attribution 4.0 International.** [原始下载](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/download.html) · [许可说明](https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) · [模型论文](https://doi.org/10.1093/nar/gkn613)
- 上游网页用衍生网格来自 [JICio/tcm-3d 固定版本](https://github.com/JICio/tcm-3d/tree/e8b9ad1c17e67a25e94406100e3fb5c296c24f7a/public/models)。上游将 BodyParts3D 4.0 模型变换为米制 Y 向上坐标并减面。本项目从其男性模型中选取 201 个骨性网格，保留结构与概念标识，重新打包坐标和索引，计算顶点法线，制作交互切面、骨块和位移动画。网格数包括复合骨的组件、籽骨等，与人体标准骨数的计数口径不同。[上游署名](https://github.com/JICio/tcm-3d/blob/e8b9ad1c17e67a25e94406100e3fb5c296c24f7a/public/ATTRIBUTION.md)
- 网页渲染使用 Three.js r160 和 OrbitControls，随仓库提供，采用 [MIT 许可](vendor/LICENSE-three.txt)。使用时无需外部 CDN。

## 定量观察与脱位

可在右栏设定终点，随时间轴观察当前帧。骨干组合示例使用局部中心线作为长轴；单位由网格的米换算为毫米。缩短示例同时包含横向错位，缩短和分离互斥。可调斜形断面的倾角以局部横断面为零度。成角与轴向旋转是两次绕模型轴的旋转分量。非组合分型保持原有运动方向，控件按移动幅度最大的骨块标定平移或转角，各骨块保持各自的比例。伤前轮廓保留在原始位置。各阶段是便于暂停观察的插值，不表示患者的受伤时序。压缩示例的百分比是预设形变倍率。

脱位新增肩前、肩后、肘后、肘外侧、髋后、髋前六个方向示例。肘部保持尺桡骨整体运动，关节平移数值沿示例位移向量计算。脱位量可自行设置，单位为 mm。中心性髋脱位涉及髋臼骨折，未收录为单纯平移动画。教案定位为教材第七章肩、肘、髋三节。卷内降面解剖网格、切面及刚体路径均有简化，未逐型通过临床审校。

自学页面专注骨性结构与分型示意。旧病例地址转至踝部骨折课程。

[界面设计备选](design/) 独立于课堂主页面。三套预览使用本站渲染的同一示例制作。执行 `python tools/build_standalone.py atlas.html` 可生成独立 HTML，内含渲染代码、模型、数据许可和教案。

教材读图参考采用本版 PDF 文件页序：桡骨远端第 361–362 页、股骨颈第 384 页、跟骨第 426–427 页及肱骨髁上第 325 页。股骨颈 Linton 角保留教材的“常小于”和“左右”措辞。长骨斜形切面默认取自教案切面法向与局部长轴的夹角；自由角度调节只作用于斜形演示。短斜形不使用滑块范围作诊断界值。

## 精细骨表面与空间观察

默认采用青瓷图版。全身仍使用同一组稳定的 201 个结构编号。首次打开时先显示轻量骨骼，下载完成后全身及局部均切换到 1,832,914 个真实源三角面。轻量版为 222,604 面。精细模型使用 BodyParts3D 男性解剖图谱的较早版本，和现有教案参考系之间采用逐骨平移、正旋转及等比缩放。保持原始三角拓扑；组合籽骨分离后按内外侧匹配。源顶点以约 0.033 mm 步长编码。该步长仅是文件的编码精度。

**精细骨表面许可**　BodyParts3D, Copyright © 2008 Life Science Integrated Database Center, licensed under [CC BY-SA 2.1 Japan](https://creativecommons.org/licenses/by-sa/2.1/jp/)。精细衍生网格按相同许可共享。来源为 [BodyParts3D STL 固定版本](https://github.com/Kevin-Mattheus-Moerman/BodyParts3D/tree/2c83c698788cff57f6317bddcf712e7acfbea7d8/assets/BodyParts3D_data)，与轻量版来源单独记录。models/detail.json 列出源文件 SHA-256、配准变换及采样表面距离。该距离用于发现版本间错配，不能证明临床精度。tools/build_detail.py 接受本地 STL 缓存路径；加 --fetch 可下载缺失源文件。需 NumPy 和 SciPy。

隔离断面可轮换查看所选骨的各个骨块。运动参照展示与骨块同步的轴线、转角弧、位移线和横向旋转参考线。关节面按端部范围及表面朝向作近似标示，已覆盖桡骨远端、胫骨平台及下关节面、股骨髁和桡骨头等课程。交线提示来自标示网格顶点与骨折边缘的空间匹配。未标示的区域、软骨和韧带不作自动判断。可遮住提示，改变视向后自行描述断线与骨端运动。

## 角度的使用范围

- 肱骨干：Kocialkowski 与 Sheridan 的 65 例队列，17–94 岁，支具治疗前影像成角均值 25°，范围 0°–60°。肱骨干组合演示采用该范围作为探索跨度；影像投影成角和三维夹角会随投影方向产生差别。[原始研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8600666/)
- 桡骨远端伸直型：以本模型掌侧缘、背侧缘的两个表面参考点及局部骨干轴计算侧面投影角。调节目标背倾会同时旋转远端骨块和腕骨。探索窗 0°–35° 选自复位前有背倾病例的测量量级；290 例老年队列原表以骨干轴为参照记录 83°–139°，以垂线为零对应约 −7° 至 49°。该队列以女性为主，不用于定义男性特异界值。掌倾为正的教材标记与界面背倾为正的目标控件分别说明。模型参考点尚未经临床逐点审校。[原始研究及表 2](https://pmc.ncbi.nlm.nih.gov/articles/PMC10041711/)
- 胫骨干扭转骨折：一项成人远端骨干队列记录了位移与短缩常并存（初始短缩平均 8.7 mm）。该结果提示应将平移、长度及旋转分开观察。其余部位只提供有边界的演示参数，不作急性损伤的统一诊断阈值。[原始研究](https://doi.org/10.1302/0301-620X.68B3.3733815)
- 学习交互参考：同一结构的隔离参见 [BoneHub](https://bonehub.github.io/Educational-Atlas/)，三维热点与自主导览参见 [Smithsonian Voyager](https://smithsonian.github.io/dpo-voyager/)。可交互踝部损伤模型曾用于医学生随机对照研究；本图谱尚未验证学习效果。[研究](https://pubmed.ncbi.nlm.nih.gov/40466756/)
